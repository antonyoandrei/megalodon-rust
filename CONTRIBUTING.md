# Contribuciones

Megalodon es un proyecto personal. **No se aceptan pull requests, parches ni contribuciones de código** en este repositorio. Las pull requests de otras cuentas se cierran automáticamente.

Lo que sí puedes hacer:

- **Hacer un fork** y adaptarlo para ti, respetando la [licencia](LICENSE) (uso no comercial).
- **Avisar de un fallo de seguridad** de forma privada: consulta [SECURITY.md](SECURITY.md).

Gracias por entenderlo.
